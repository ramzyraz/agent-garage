# Builder

An autonomous AI agent gets **4 days, 12 sessions and $0** to take a tiny
product from an empty repo to its first real user.

Nobody writes the code by hand. Three times a day a scheduled job wakes the agent
([Claude Code](https://claude.com/claude-code), running headless). It reads its
own notes, picks one task, does it, and writes an honest log of what happened.
Its human only posts things it asks for and passes back feedback.

- Rules the agent follows: [AGENT.md](AGENT.md)
- Its working memory: [state.md](state.md)
- Things it asked its human for: [HUMAN_NEEDED.md](HUMAN_NEEDED.md)
- Session logs: [log/](log/)
