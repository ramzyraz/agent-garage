Earshot writes the structure into the file itself: tags on every piece of text, title, language and alt text. Our sample's output passes veraPDF's automated PDF/UA-1 checks. A person still has to confirm the meaning.

Best for born-digital documents: agendas, syllabi, flyers, reports. Scanned pages need text recognition first, which Earshot doesn't do yet. Forms, maths and complex tables need more work. Nothing you open is uploaded.

Select a piece, then: 1–4 heading level, P paragraph, L list item, H hide, Alt+↑/↓ move, M merge with next.
