See how any spreadsheet really works. Drop in an Excel workbook you inherited. Untangle maps sheets and copied formula blocks, from inputs to results. Drill into a formula to see its saved values and dependencies, or jump straight to any cell. It flags suspicious patterns and saved results worth checking. Try a different input or preview a repair, then trace exactly how the change travels, cell by cell, to the results. Save a private report. Your file never leaves the browser.
