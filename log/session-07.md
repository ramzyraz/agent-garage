# Session 07 · Day 3 · Claude Code

**Goal this session:** the human removed all limits and said Second Sense isn't "wow". Build something that is.

## What I did
- Read the human's new note (#8): no budget, size or deadline limits; "build something I can show people".
  There were still no replies about launch or usage. So the right move was a new flagship, not more Second Sense.
- Built **Namesake**: type any name and a planet forms from it, live, as you type. Same name, same world,
  for everyone. It's now the homepage.
  - The planet is one WebGL fragment shader (~200 lines): fractal terrain, oceans with a sun glint, ice caps,
    clouds, city lights on the night side, lava cracks, banded gas giants with a storm, rings with shadows,
    atmosphere glow and stars. No 3D models, no images.
  - `world.js` turns the name into a seed, then into one of 7 world kinds, a palette, a catalogue number,
    a field note ("There are cities on the night side. Nobody has answered our signal yet.") and six facts.
  - Drag to spin, scroll/pinch to zoom, 🎲 for a random name, a "Copy link" button, and a "Save postcard" button
    that makes a 1080×1350 image for sharing (the native share sheet on phones).
- Moved Second Sense to `/second-sense/` (linked from the footer) and updated its test paths.
- Tests: 3 new unit tests (same name gives the same world; all 7 kinds appear in 400 names; edge cases).
  A new headless-Chrome check renders real frames with software WebGL, types a name, builds a postcard and
  saves screenshots. I looked at every screenshot. The old Second Sense browser test still passes.

## What broke / surprised me
- The first render worked, which surprised me for a 200-line shader written in one go. Looking at it found
  real problems: ice worlds were 95% white, and on phones the planet sat behind the info card. Both are fixed.
- The browser test failed three times, all because of the test, not the app: triple-click doesn't select
  text on emulated touch screens, resizing the canvas for the postcard clears it until the next frame,
  and the missing favicon logged a 404. I added a 🪐 favicon.
- Software WebGL is so slow that my own "lower the resolution on slow devices" code kicked in during the
  screenshots and made them blocky. `?hq` turns it off for screenshots.

## What I learned
- We built two products for "a first real user" and the human was unimpressed both times. The brief
  is now different: impress first. Something that looks impossible gets shown to people; something
  merely useful doesn't.
- I can't judge performance on a real phone from here. That's the biggest risk.
